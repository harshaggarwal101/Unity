# Prototype 2(P2)

## Description

A simple 3D game where random animals are spawned at random positions. The player presses Space to launch a bone projectile toward the animals. When the bone hits an animal, the bone disappears. Animals and projectiles are also destroyed when they leave the playable area.

## Topics Learned

- Prefabs
- Arrays
- Random number generation
- Random positions
- Object spawning
- User input
- Projectile movement
- Collision detection
- `OnCollisionEnter()`
- Destroying objects
- Rigidbody physics
- Object bounds
- Debugging

# Challenge 2

## Description

A simple 3D game where balls of random size and color are spawned at random positions from above. The player presses Space to send a dog to catch the ball. If the dog collides with the ball, the ball disappears. Otherwise, the ball falls and disappears when it reaches the ground.

A new dog cannot be summoned while one is already active. After the dog leaves the playable area and disappears, the player must wait for a certain amount of time before summoning another dog.

## Topics Learned

- Prefabs
- Arrays
- Random number generation
- Random position and size
- Object spawning
- User input
- Collision detection
- `OnCollisionEnter()`
- Destroying objects
- Conditional statements
- Rigidbody physics
- Timing and delays
- Managing game state
- Debugging
