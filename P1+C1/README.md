# Prototype 1(P1)

## Description

A simple vehicle game where the player controls a vehicle and avoids obstacles on the road.

## Topics Learned

- Unity project setup and asset import
- Scene setup and object placement
- Unity Editor interface and 3D navigation
- GameObjects and Components
- C# scripts and methods
- `Start()` vs `Update()`
- Variables and parameters
- User input
- `Time.deltaTime`
- Transform, Translate and Rotate
- Empty GameObjects
- Colliders and Rigidbody
