# Balloon Game

## Description

A Unity game based on a partially completed project containing multiple errors and missing functionality. The objective was to debug the existing scripts and complete the game so that it behaved correctly according to the provided reference video.

All required objectives and bonus objectives were completed **without using the provided hints**.

## Skills Learned

- Debugging Unity C# scripts
- Identifying and fixing `NullReferenceException` errors
- Using `GetComponent<>()` to access Unity components
- Working with `Rigidbody` and physics forces
- Using `InputAction` for player input
- Controlling player movement with physics
- Using boolean variables to control game states
- Implementing game-over logic
- Moving objects using `Transform.Translate()`
- Using `Invoke()` for timed function calls
- Debugging method name and spelling errors
- Working with Particle Systems
- Positioning child Particle Systems with their parent objects
- Creating seamless repeating backgrounds
- Detecting collisions using `OnCollisionEnter()`
- Applying impulse forces on collision
- Implementing height and movement restrictions
- Adding and triggering sound effects
- Debugging and completing an existing Unity project
