## Debugging & Problem Solving

Some of the projects in this repository were provided as partially completed or intentionally broken projects. Rather than building everything from scratch, I had to:

* Read and understand existing C# scripts
* Identify errors and incorrect behavior
* Debug the existing implementation
* Determine what was missing or broken
* Implement the required functionality
* Compare the result with the expected behavior shown in the reference material

For some of these projects, I completed the objectives without using the provided hints, relying on debugging, experimentation, and understanding of the Unity systems involved.
