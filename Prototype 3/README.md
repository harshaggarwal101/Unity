# Prototype 3 – Endless Runner

## Description

A simple endless runner game.The player controls a character, jumps over obstacles, and survives as long as possible while using sound and visual effects to enhance the gameplay.

## Topics Learned

- Player Input
- Player Movement
- Jump Mechanics
- Collision Detection
- Prefabs
- Object Spawning
- Coroutines
- Timers
- Audio
- Particle Systems
- Scrolling Backgrounds
- Game Logic
- Debugging
